# Passport RP — Fabric 26.3

Игровой RP-мод паспорта для Minecraft Java Edition 26.3 / Fabric.

## Что есть

- Крафт `Паспортный бланк` из книги, бумаги, кожи и красителя.
- Одноразовое оформление: после выдачи паспорт получает владельца, серию, номер и неизменяемую дату рождения.
- Автоматическая случайная серия из 4 цифр и номер из 6 цифр.
- Поля паспорта: фамилия, имя, отчество, пол, дата/место рождения, гражданство РФ, дата выдачи, орган выдачи, регистрация.
- Любой игрок может оформить паспорт себе или выдать его другому игроку, если держит чистый бланк в основной руке.
- Имя/фамилия/отчество владельца меняются только через серверное голосование.
- Голосование требует строго больше 50% голосов от числа игроков, которые были онлайн в момент открытия голосования. Окно голосования: 60 секунд.
- Регистрацию можно менять владельцу без голосования.
- Серия, номер, дата рождения, место рождения, пол и дата выдачи блокируются после оформления.
- Правка выполняется только сервером, поэтому клиент не может подменить данные паспорта обычным NBT-редактором.
- Паспорт можно посмотреть ПКМ по предмету или командой `/passport info`.

## Команды

`/passport help` — помощь.

`/passport info` — показать паспорт в основной руке.

`/passport fill "Фамилия" "Имя" "Отчество" М 01.01.2000 "Город, область" 26.09.2026 "Кто выдал документ" "Адрес регистрации"`

Эта команда оформляет чистый бланк на самого исполнителя.

`/passport issue <player> "Фамилия" "Имя" "Отчество" М 01.01.2000 "Город, область" 26.09.2026 "Кто выдал документ" "Адрес регистрации"`

Эта команда оформляет чистый бланк на другого игрока и автоматически пытается положить готовый паспорт в его инвентарь.

`/passport namechange "НоваяФамилия" "НовоеИмя" "НовоеОтчество"` — открыть голосование за изменение ФИО владельца паспорта в основной руке.

`/passport vote yes` или `/passport vote no` — голос за активное голосование.

`/passport registration "Новый адрес регистрации"` — изменить регистрацию владельца паспорта в основной руке.

## Крафт

```
R P R
L B L
P P P
```

R = красный краситель
P = бумага
L = кожа
B = книга

## Сборка

Для Minecraft 26.3 проект рассчитан на Java 25, Fabric Loader 0.19.5, Fabric Loom 1.17 и Fabric API 0.161.0+26.3.

В окружении с Java 25 и доступом Gradle к Maven-репозиториям:

`gradle build`

Готовый JAR появится в `build/libs/`.

Примечание: это игровая RP-механика и стилизованный предмет. Он не является настоящим российским паспортом и не воспроизводит государственный документ один-в-один.

## Как играть

1. Скрафти `Паспортный бланк` по рецепту с книгой.
2. Держи бланк в основной руке. Любой игрок может оформить его командой `/passport fill ...` на себя. Для выдачи другому игроку используй `/passport issue <игрок> ...`.
3. После выдачи ПКМ по паспорту открывает его данные в чате.
4. ФИО: владелец запускает `/passport namechange ...`, затем сервер голосует 60 секунд через `/passport vote yes` или `/passport vote no`. Нужно строго больше 50% от игроков, которые были онлайн в момент запуска.
5. Регистрация меняется владельцем напрямую: `/passport registration "Новый адрес"`.

## Что зафиксировано навсегда

После первого оформления нельзя обычными командами заменить дату рождения, серию, номер, гражданство, пол, место рождения, дату выдачи или орган выдачи. Серия и номер генерируются сервером случайно и имеют фиксированный формат `0000` + `000000`.

## Важная оговорка

Это игровой RP-документ в стиле российского паспорта, а не точная копия государственного документа. Названия, логика голосования и дополнительные поля предназначены для Minecraft-сервера.

## Сборка

Для Minecraft 26.3 нужен Java 25. В установленном Gradle 9.6+ из корня проекта выполни `gradle build`. Готовый JAR появится в `build/libs/`.
