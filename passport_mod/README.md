# Passport RP — Fabric 26.3

Игровой RP-мод паспорта для Minecraft Java Edition 26.3 / Fabric / Java 25.

## Геймплей

Вся обычная работа с паспортом выполняется через **паспортный стол** и GUI.

- ПКМ по `Паспортному столу` открывает интерфейс.
- Чистый бланк оформляется через форму GUI.
- После оформления сервер создаёт серию, номер, ID, UUID владельца, дату выдачи и орган выдачи.
- Основной документ хранится в отдельном **«Кармане для паспорта»** и не занимает слот из обычных 36 слотов.
- Кнопка `P` добавляется в инвентарь и открывает карман; сервер также отклоняет попытки положить туда не-паспорт.
- Перезаход, смерть и перезапуск мира не удаляют документ: карман и данные хранятся в серверном SavedData.
- Заполненный паспорт имеет меню управления: просмотр, ФИО, регистрация, брак, дети, военная служба, дополнительные сведения, статус и замена.

## Смена ФИО

Смена фамилии, имени, отчества или всего ФИО запускается из GUI и проходит через сохранённое серверное голосование.

- Для каждого игрока отдельный cooldown **30 реальных минут**.
- Cooldown хранится сервером и не сбрасывается перезаходом.
- Голосование длится 60 секунд и доступно только тем игрокам, которые были онлайн при его старте.
- Голосовать можно только через GUI.

## Показ паспорта

Единственная игровая команда для адресного показа:

`/passport show <player>`

Сервер проверяет:

- показывается только собственный основной паспорт отправителя;
- один мир;
- расстояние максимум 4 блока;
- запрос действует 15 секунд;
- получатель должен подтвердить `/y` или `/n`;
- после `/y` оба игрока получают один и тот же полноценный GUI просмотра паспорта; вторая сторона не получает паспортные данные в чат.

Служебная команда:

`/passport help`

## Паспорт

Документ отображается как отдельная многостраничная книга-паспорт с 12 страницами и портретом владельца из его Minecraft-скина.

Структура страниц:

1–2 — основные данные и портрет;
3–4 — регистрация;
5–6 — брак;
7–8 — военная служба;
9–10 — дети;
11 — дополнительные сведения;
12 — статус и история изменений.

Статусы: `Действителен`, `Утерян`, `Недействителен`, `Заменён`.

При замене старый документ переносится в серверный архив как `Заменён`, а новый получает новую серию, номер и ID с сохранением истории.

## Текстуры и Creative

- 16 цветовых вариантов паспорта имеют отдельные подробные pixel-art текстуры 32×32 и 3D item model.
- Паспортный стол имеет отдельные block textures, blockstate и модель с ножками, столешницей и лицевой панелью.
- Все варианты паспорта и стол добавляются в Creative Inventory.
- Build-задача `verifyPassportResources` проверяет наличие item definitions, моделей, blockstate и текстур.

## Сборка на GitHub Actions

Workflow `.github/workflows/build.yml` использует Java 25, Ubuntu 24.04, Gradle 9.5.1 и современные версии checkout/setup-java/setup-gradle.

Артефакт workflow: `passport-mod-jar`.

Основной файл после сборки: `build/libs/passport-rp-1.0.0.jar`.

Примечание: мод является игровой RP-механикой и не является настоящим государственным документом.
